## Seed Automation
To download, upload to Cloudinary (`vakratund/home`), and populate the database:
```bash
npm run home-slider:seed
```
Dry-run mode (validates URLs and checks database state without uploading):
```bash
npm run home-slider:seed -- --dry-run
```
